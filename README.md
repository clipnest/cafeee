# Milton's Coffee Experience ☕

A premium, Awwwards-level scrollytelling website featuring a cinematic scroll-controlled iced coffee animation with 190 high-speed photography frames.

## Features

- 🎬 **Scroll-linked canvas animation** — 190 frames driven by scroll position
- ✨ **TextEffect** — character-by-character text reveals
- 🎯 **Tilt** — 3D perspective product cards
- 🔮 **GlowEffect** — animated coffee-palette CTA buttons
- 🖱️ **Custom Cursor** — "VIEW +" interaction on products
- 🚀 **Apple-style Dock** — floating navigation with magnification
- 🌗 **Theme toggle** — dark espresso ↔ light cream

## Tech Stack

- **Next.js 14** (App Router, static export)
- **TypeScript**
- **Tailwind CSS**
- **Framer Motion**
- **HTML5 Canvas**

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Build for Production

```bash
npm run build
```

Static files are generated in the `out/` directory.

## Deploy

Push to `main` branch — GitHub Actions will automatically build and deploy to GitHub Pages.
